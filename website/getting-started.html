Getting Started with VORTEX AI

Follow this technical guide to understand how VORTEX AI interacts with MetaTrader 5, verify broker compatibility, inspect telemetry freshness, and safely monitor automated multi-account operations.

1

Platform Architecture Overview

VORTEX AI provides transparent, read-only telemetry monitoring for institutional and quantitative MetaTrader 5 fleet operations.

What It Monitors

Broker-confirmed account balances, equity, margin levels, open positions, closed trade history, and system heartbeat.

Local MT5 vs Website

The trading bot runs on a dedicated Windows workstation alongside MetaTrader 5. The website is an isolated edge gateway that displays read-only snapshots.

Website Login vs MT5

Logging into the VORTEX AI website grants access to view fleet telemetry. It is completely decoupled from your broker credentials.

Read-Only Guarantee: The VORTEX AI website contains zero execution code. It is mathematically impossible for a website visitor or operator to submit, modify, or close broker orders from the dashboard.
2

MetaTrader 5 Installation

VORTEX AI requires an authentic MetaTrader 5 terminal running on your local Windows PC or server.

  1. Obtain MT5: Download MetaTrader 5 from your verified broker or directly from MetaQuotes Official Distribution ↗.
  2. Install Terminal: Complete the installation wizard. For multi-account fleets, install terminals in isolated directories (e.g. C:\MT5_Terminals\account_003) using the /portable flag.
  3. Demo Account Login: Launch MT5, click File → Open an Account, search for your broker server (e.g., VantageMarkets-Demo), and register or log in with your demo credentials.
  4. Confirm Market Data: Check the Market Watch window. Verify live green tick data for instruments such as EURUSD, XAUUSD, and BTCUSD.

Connecting an Account Securely

How local account telemetry connects to the cloud dashboard without exposing sensitive broker passwords:

CRITICAL SECURITY PRINCIPLE: Never enter or paste your MT5 broker trading password or master password into any website form, browser prompt, or third-party cloud service. VORTEX AI will NEVER ask for your broker password online.
  • Local Workstation Storage: Broker login numbers and credentials are stored strictly on your local PC via Windows Credential Manager (advapi32.dll) or local .env.
  • Local Publisher Daemon: A local background Python task (app/vortex_dashboard.py) reads account metadata (balance, equity, positions) via the official Python MetaTrader5 bridge.
  • HMAC-SHA256 Signed Ingestion: The publisher formats a sanitized JSON snapshot, signs it with a 64-character HMAC secret, and posts it over HTTPS to the secure Vercel Edge gateway.
  • Cloud Isolation: The cloud gateway validates the cryptographic signature and timestamp before storing the snapshot in Supabase. Passwords are never sent or stored.

Demo Testing & Telemetry Verification

Always begin with a verified demo trading account to confirm system telemetry before connecting any real capital.

1. Check Feed Freshness

Look for the ● CONNECTED / FRESH badge. If it shows ⚠ STALE, the publisher is stopped or lag exceeds 30s.

2. Verify Account Mode

Confirm the DEMO badge is displayed. Never assume an account is demo based solely on server name.

3. Inspect Provenance

A STALE CACHE badge means you are viewing preflight cached data, not a live streaming feed.

Troubleshooting Common Issues

Quick diagnostic solutions based on verified system implementation:

MT5 terminal not installed or path not found

Ensure MetaTrader 5 64-bit is installed at C:\Program Files\MetaTrader 5\terminal64.exe or inside the account's configured portable terminal directory (e.g. C:\MT5_Terminals\account_003). Verify the path in accounts.json.

Broker login failure (AUTH_FAILED_ERROR_6)

Error code 6 signifies invalid login credentials or wrong broker server. Verify that your MT5 account number, password, and exact broker server name (e.g. VantageMarkets-Demo) match your broker account confirmation email.

Account shows DISCONNECTED or UNAVAILABLE

Verify that the MetaTrader 5 desktop application is logged in and market quotes are updating in the bottom-right connection status bar. If MT5 is offline, restart your internet connection or check broker maintenance hours.

Feed shows STALE or STALE CACHE

The dashboard marks any snapshot older than 30 seconds as STALE. If the publisher background process is paused (such as during preflight safety audits), the dashboard transparently flags the data as static preflight cache.

Account mode shows UNKNOWN

The system refuses to guess account mode from balances. If the broker MT5 session does not populate the authoritative trade_mode property, UNKNOWN is safely returned until full metadata is received.

API Authentication Failure (HTTP 401)

Your session JWT has expired or is invalid. Sign out and sign in again via Sign In using your authorized operator email or Cloud SSO link.

Cloud Telemetry Unavailable (HTTP 503)

The Supabase staging database or Vercel edge gateway is undergoing migration or maintenance. Check the Status Page for active infrastructure health.
